# Spinscore – CD & DVD E-Commerce Website

## Project Overview

Spinscore is an e-commerce website developed as part of a group coursework project for the COM109 module at Ulster University.

The website was designed to allow users to browse CDs and DVDs, view product information, add items to a shopping cart and complete a checkout process.

The aim of the project was to develop a functional and user-friendly website while gaining practical experience in front-end web development and working collaboratively as a team.

## Technologies Used

- **HTML** – Website structure and content
- **CSS** – Website styling, layout and design
- **JavaScript** – Interactive functionality, shopping cart and checkout validation

## Website Design

The website follows a consistent design throughout, with a focus on simple navigation and usability.

**Colour Scheme:**
- Black – Main background
- White – Header and contrasting elements
- Orange (#f46106) – Accent colour

**Website Layout:**
- Navigation header with links to the main pages
- Separate CD and DVD product sections
- Product images and information
- Shopping cart and checkout pages
- Contact and review sections
- Footer containing copyright and educational-use information

## Key Features

### Product Browsing
- Separate sections for CDs and DVDs
- Product listings with images and information
- Navigation between the different website pages

### Shopping Cart
- Add products to the shopping cart
- Display selected products and their prices
- Automatically calculate the total cost
- Remove individual products from the cart
- Clear the entire shopping cart

### Checkout
- Dedicated checkout page
- Form validation for required customer information
- Order total calculation
- Order confirmation with an order number
